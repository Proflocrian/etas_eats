# EtasEats — "11:11" theme spec

Target: iPhone 15 PWA, standalone, 393×852 CSS px @3x, portrait. Safe areas: top 59px, bottom 34px.
Visual reference: `11-11 Theme.dc.html` (five themed screens).

---

## 1 · Concept

The theme imagines a quiet room at 11:11. The app sits in deep denim, like the darkest ribbon of the watercolour. Sheets slide up as the full marbled wave, with their fields on a frosted ice panel.

The marbled wave appears in only three places:
- behind the entry form and entry details sheets
- a faint strip under the status bar
- the 11:11 theme card in Settings

The thin white heart-clock appears where it means something:
- at the top of each sheet
- as a faint watermark in Settings and About
- beside the 11:00 row on the calendar

The 🩵 accent `#A8D8EA` is used only for "this one": the selected tab, today, the active toggle, Save. Because it is rare, it stays special. Small text always sits on light ground with dark ink, or on denim with high-contrast white or ice text.

## 3 · Font

**Quicksand** (Google Fonts, SIL Open Font License). It is a geometric rounded sans with a thin, even stroke, so it matches the line-art heart and reads as gentle without looking childish.

- Weights: **500** body, **600** labels, **700** titles and chips. Never go below 500 at 11–13px.
- Self-host the variable woff2 (~40KB, Latin subset) in `/public/fonts/`. This means nothing is fetched at runtime and the font works offline.

```css
@font-face {
  font-family: 'Quicksand';
  src: url('/fonts/Quicksand-VariableFont_wght.woff2') format('woff2');
  font-weight: 300 700;
  font-display: swap;
}
--font: 'Quicksand', ui-rounded, 'SF Pro Rounded', system-ui, sans-serif;
```

On iOS, `ui-rounded` falls back to SF Pro Rounded, which looks close to Quicksand if the font file fails to load.

## 4 · Treatments

### #1 Denim surface (`appBg`)
A vertical gradient with no pattern.

```css
--appBgSurface: linear-gradient(180deg, #2A5986 0%, #23507D 34%, #1F4873 100%);
--gridLine: #44709C;      /* hour lines, solid */
--gridHalfLine: #305C88;  /* half-hour lines, dashed */
--gridCol: #34618D;       /* day column dividers */
```

### #2 Marbled wave
One inline SVG tile (480×360), 124 paths, about 50KB raw / 64KB URL-encoded, used as a CSS data-URI. **No raster asset is needed.**

The tile is about 34 sine-wave strokes in denim → powder → cream, plus fine white hairlines, on an `#E9EEF1` ground. The tile is seamless in both directions: the wave periods divide the tile width, paths run 32px past each edge so stroke ends never show, and every line is also drawn one tile-height above and below so it wraps vertically, and each line's phase, colour, width and opacity cycle exactly once over the 34 lines so the last line flows into the first. (The earlier version clipped lines at the tile edges, which showed as a pale seam when the wave drifted.) The tile sits on an oversized child rotated −14° to get the diagonal flow.

Generator: **call it once at app boot** and set the result as a CSS variable (`document.documentElement.style.setProperty('--waveSvg', makeWave())`). Generating it takes about 1ms and keeps the bundle small; pasting the string as a constant also works but adds the size above to your JS.

```js
export function makeWave() {
  // Seamless in both directions:
  //  - every sine period divides W, so x=0 and x=W match
  //  - paths overrun the tile by 32px each side, so stroke caps never show at the edge
  //  - each line is drawn three times (y-H, y, y+H), so lines crossing the top/bottom edge wrap
  const W = 480, H = 360, n = 34;
  const cols = ['#1F4E86','#2F67A3','#5C8FC4','#8DB4DA','#B9D3EA','#DCE8F2','#F1F0EA'];
  //  - every per-line term (phase, colour, width, opacity) is periodic over n, so line n ≡ line 0
  const T = i => (2*Math.PI*i)/n;
  const line = (y0, i, amp) => {
    let d = '';
    for (let x = -32; x <= W + 32; x += 16) {
      const y = y0 + amp * Math.sin((2*Math.PI*x)/(W/2) + 3*T(i))
                   + 5 * Math.sin((2*Math.PI*x*3)/W + 5*T(i));
      d += (x === -32 ? 'M' : 'L') + x + ' ' + y.toFixed(1);
    }
    return d;
  };
  const wrap = (y0, i, attrs) =>
    [-H, 0, H].filter(dy => y0 + dy > -40 && y0 + dy < H + 40).map(dy => `<path d="${line(y0 + dy, i, 14)}" ${attrs} fill="none"/>`).join('');
  let p = '';
  for (let i = 0; i < n; i++) {
    const y0 = (i*H)/n;
    const band = Math.sin(2*T(i)) + 0.6*Math.sin(T(i) + 1);
    const ci = Math.max(0, Math.min(6, Math.round(((band+1.6)/3.2)*6)));
    const w = (4 + 7*Math.abs(Math.sin(4*T(i)))).toFixed(1);
    const o = (0.55 + 0.4*Math.abs(Math.cos(3*T(i)))).toFixed(2);
    p += wrap(y0, i, `stroke="${cols[ci]}" stroke-width="${w}" stroke-opacity="${o}"`);
  }
  for (let i = 0; i < n*2; i++) {
    const y0 = (i*H)/(n*2) + 3;
    p += wrap(y0, i/2, 'stroke="#fff" stroke-width="0.8" stroke-opacity="0.35"');
  }
  const svg = `<svg xmlns="http://www.w3.org/2000/svg" width="${W}" height="${H}" viewBox="0 0 ${W} ${H}"><rect width="${W}" height="${H}" fill="#E9EEF1"/>${p}</svg>`;
  return 'url("data:image/svg+xml;utf8,' + encodeURIComponent(svg) + '")';
}
```

```css
.wave { position:absolute; inset:0; overflow:hidden;
        opacity:var(--o,1); mask-image:var(--mask,none); -webkit-mask-image:var(--mask,none); }
.wave::before { content:""; position:absolute; inset:-40%;
        background:var(--waveSvg) 0 0 / 480px 360px repeat;
        transform:rotate(-14deg) translateZ(0); backface-visibility:hidden;
        animation:ttDrift 140s linear infinite; }
```

Where it is used:
- **Entry form + entry details sheets:** full opacity as the whole sheet background. Drift is 160s. On top of it is a scrim, `linear-gradient(180deg, rgba(30,70,112,.05), rgba(27,63,100,.35))`.
- **Header strip** (Calendar, Triggers): 120px tall at the top of the screen, `--o:.26`, `--mask: linear-gradient(180deg,#000 0%,rgba(0,0,0,.6) 45%,transparent 100%)`. It sits behind the status bar and header only, never the calendar grid.
- **Settings theme card (11:11):** the right 150px of the card, `--o:.55`, `--mask: linear-gradient(90deg,transparent,#000 75%)`.

### #3 Heart-clock SVG
Stroke only, `currentColor`. `vector-effect: non-scaling-stroke` keeps the line hairline-thin at any size. The hour hand points to 11 (−30°) and the minute hand to 11 minutes (+66°), both from the centre (50,50).

```html
<svg viewBox="0 0 100 96" fill="none" stroke="currentColor"
     stroke-width="1.5" stroke-linecap="round" stroke-linejoin="round">
  <path vector-effect="non-scaling-stroke"
        d="M50 88C20 64 6 48 6 32 6 18 16 8 29 8c10 0 17 6 21 14 4-8 11-14 21-14 13 0 23 10 23 24 0 16-14 32-44 56Z"/>
  <path vector-effect="non-scaling-stroke" d="M43 38 50 50 68 42"/>
  <circle cx="50" cy="50" r="2.6" fill="currentColor" stroke="none"/>
</svg>
```

Where it appears:
- **Sheets:** 42px, white, stroke 2.2, pulsing (motion b). Centred in the 66px wave band under the grabber.
- **Settings + About watermark:** 260px, white at 7% opacity, stroke 1.2. Positioned `right:-70px; top:30px` so it bleeds off the top-right edge.
- **11:11 theme card icon:** 22px, white.
- **Calendar:** a 9px 🩵 heart outline (no hands, stroke 1.4) beside the "11:00" time label.

### #4 Frosted sheet panel
All sheet content (header and fields) sits on one panel over the wave, so text stays dark-on-light wherever the wave runs.

```css

```

The 42px bottom margin lets the wave show around the home indicator, which is white (`#F4F7FB`) on sheets.

## 5 · Per-screen notes

**Calendar (readability-critical)**
- The grid sits on the solid denim gradient with no pattern.
- Hour lines are solid `#44709C`, half-hours dashed `#305C88`, columns `#34618D`.
- Today's column gets a 7% 🩵 wash, `rgba(168,216,234,.07)`. Today's date is a 28px 🩵 disc with navy text, and the weekday label above it is 🩵.
- Weekday labels and time labels are `#A9C3DD` (4.6:1). Date numbers are `#F4F7FB`.
- Entry chips are light fill with dark ink, a 1px border and a 3px left accent in the type's border colour. Font is 11px/700, with a 6px radius.
- This gives every type contrast against denim, and each type keeps its own hue: teal (food), violet (activity), apricot (symptom).
- Flagged entries keep the 🚩 emoji inside the chip.

**Header strip:** the wave at 26% opacity fading out by ~120px, behind the status bar and month row only.

**Week/Day toggle**
- Track `#1C426A` with a 1px `#4A729B` border, 36px tall.
- The 🩵 thumb slides between Week and Day. Text on the thumb is `#12304F`; the other label is `#DCE8F2`.

**Filter chips**
- Fill `pillBg`. Idle border is 1.5px `pillBorderIdle`.
- Selected "All" gets a 2px `allPillBorder` plus a 3px halo at 18% of the same colour.
- Selected type chips use their `*EntryBorder` colour; the selected trigger chip uses `triggerPillBorder`.
- Height 38px, with at least a 44px tap area. 1px `#4A729B` dividers separate the groups.

**FAB**
- 60px white circle, navy "+" (`#1F4A78`, stroke 2.2), hairline 🩵 ring `0 0 0 1px rgba(168,216,234,.6)`, shadow `0 8px 22px rgba(8,24,48,.35)`.
- During the 11:11 minute only, a 🩵 ripple runs (motion c). The rest of the day it is still.

**Entry form + entry details sheets**
- Background: the full drifting wave, with a white grabber and the pulsing heart-clock in the top band. A 55% scrim sits behind the sheet.
- Content is on the frosted panel (treatment #4).
- Inputs are white with a 14px radius, 1px `#CFDCE8` border and 48px height. Text `#16324F`, placeholder `#7891AA`.
- Labels are 15px/700 `#16324F`; muted labels are `#5B7590`.
- The Save pill is 🩵 with navy text and a soft shadow.
- Type pills on the sheet are white. Idle border is `#CFDCE8`; the selected pill gets a 2px type border with a 3px 15% halo.

**Switches (No/Yes)**
- The track is an inset: `#1C426A` on denim, `#E6EEF5` on sheets.
- "No" thumb: near-white `#F4F7FB` with navy text on denim; navy `#16324F` with white text on sheets.
- "Yes" on a Possible Trigger switch: rose `#F2A7B5` with `#4E1626` text. Any other "Yes": `primaryAction`.

**Triggers**
- The segmented control slides a 🩵 thumb. Active text is `#12304F`; inactive is `#DCE8F2`.
- Cards use `settingsButtonBg` with a `#3E6994` border and a 20px radius.
- Symptom titles use `symptomEntryBorder`, so "symptom" reads warm on every screen. Dates and "before" labels are `#B9CEE3` / `#A9C3DD`.
- A large white **"11:11"** (Quicksand 500, 44px, letter-spacing .04em) is fixed at the bottom of the background, 118px above the screen edge (just above the nav). It uses `pointer-events:none`, and content scrolls over it.

**Bottom nav**
- `navBg` with a 1px `#2F5880` top rule, 56px plus the 34px safe area.
- Selected tab: white label at 700, full-opacity emoji, and a 22×3px 🩵 marker at the top edge.
- Unselected tabs: emoji at 72% opacity, label `navFont` at 600.

**Settings**
- Heart-clock watermark top-right.
- Section labels are 13px/700 `#A9C3DD`.
- Row cards use `settingsButtonBg` with `#3E6994` dividers. Checkmarks are 🩵.

**Settings theme card (11:11)**
- Selected state: 2px 🩵 border, `0 0 0 4px rgba(168,216,234,.16)` halo, and a 26px 🩵 check disc with a navy ✓.
- The card shows the 22px heart-clock icon, the name "11:11", and the wave fading in on the right.
- Swatches: `#A8D8EA` · `#4FB3A2` · `#8E86DA` · `#F2A684` · `#F2A7B5`.

**About:** same background as Settings: the denim gradient plus the heart-clock watermark.

**Danger Area**
- Card `#3A2F4F` with a 1px `#E07A80` border. Title and text `#FFD4D6`.
- Destructive button `#E07A80` with `#3A0F14` text.

## 6 · Motion

```css
/* a. Wave drift: one tile per 140–160s. Moving background-position is cheap for the GPU. */
@keyframes ttDrift { from { background-position:0 0 } to { background-position:-480px 0 } }

/* b. Heart breath (sheet heart-clock), 6s */
@keyframes ttBeat {
  0%,100% { opacity:.82; filter:drop-shadow(0 0 0 rgba(168,216,234,0)) }
  50%     { opacity:1;   filter:drop-shadow(0 0 10px rgba(168,216,234,.85)) }
}
.heart-pulse { animation: ttBeat 6s ease-in-out infinite; }

/* c. FAB ripple: only while the clock reads 11:11 (AM or PM) */
@keyframes ttRing { from { transform:scale(1); opacity:.6 } to { transform:scale(1.5); opacity:0 } }
.fab { position:relative; }
.fab[data-eleven]::after { content:""; position:absolute; inset:0; border-radius:50%;
  border:2px solid #A8D8EA; animation: ttRing 3.2s ease-out infinite; }

/* d. Sliding thumbs (existing toggles), re-eased */
.thumb { transition: transform .34s cubic-bezier(.3,.8,.3,1), background-color .3s; }

/* e. Sheet enter */
.sheet { transition: transform .42s cubic-bezier(.2,.9,.25,1); }

@media (prefers-reduced-motion: reduce) {
  .wave::before, .heart-pulse, .fab::after { animation: none; }
  .thumb, .sheet { transition-duration: .01s; }
}
```

- For (c), check the clock once a minute, aligned to the start of the minute. Set `data-eleven` while `h % 12 === 11 && m === 11`.
- Pause the wave (`animation-play-state: paused`) whenever `document.hidden` is true, to save battery.
